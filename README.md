## 💡 Summary of Methodology & Way of Thinking

In competitions with over 3,500 competitors, public leaderboards often become congested with near-identical blends (offline Spearman rank correlations between top public blends exceeded `0.9995`). 

This project focused on:
1. **Synthetic Data Reverse-Engineering:** Dissecting the underlying CTGAN generator, discovering hard cutoffs, and decoding numeric rounding artifacts.
2. **Measured Feature Ladder:** Verifying every single feature step on an out-of-fold 5-Fold Stratified cross-validation baseline to eliminate validation leakage.
3. **Multi-Model Frontier Ensembling:** Merging structurally diverse algorithms (Generator-Aware Ridge, LightGBM, CatBoost, and XGBoost) in quantile rank and probit spaces.

---

### 1. Reverse-Engineering & Deterministic Boundary Analysis

Synthetic tabular data generated by CTGAN contains mathematical boundary conditions that decision trees struggle to approximate without assistance:

- **The "Millionaire Cliff":** Every single record with `Annual_Income_USD >= $170,537` in the training set (393/393, 100%) had `Will_Buy_EV == 'Yes'`.
- **Peaked Boundary Floors:**
  - `Annual_Income_USD == 30,000`: 9.2% of rows sit exactly at the floor with a 4.4% positive rate (vs 18.8% elsewhere).
  - `Daily_Commute_km == 5.0`: 21.6% of rows sit at this exact synthetic cluster.
- **Underlying Propensity Formula:** The target followed an additive latent buying score:
  $$\text{Score} \approx 1.2 \times \frac{\text{Income}}{100\text{k}} + 0.6 \times \text{Concern} + 2.0 \times \text{Subsidy} - 1.0 \times (\text{Anxiety}_{\text{Med}}) - 3.0 \times (\text{Anxiety}_{\text{High}})$$
  This pure formulation alone yielded **0.93769 ROC-AUC** before any tree splits.

### 2. The Feature Ladder (CV: 0.94186 ➔ 0.94550+)

Using a fixed 5-Fold Stratified LightGBM setup, features were measured sequentially to isolate true predictive gains:

| Rung | Features Added | Total Features | 5-Fold OOF AUC | $\Delta$ Gain |
| :---: | :--- | :---: | :---: | :---: |
| **0** | **Baseline:** Raw features + 6 domain interactions (`subsidy × concern`, ordinal anxiety, total charging, log income, income floor flag) | 18 | 0.94186 | — |
| **1** | **Digit Decomposition:** Integer and decimal place digits (`_d0` to `_d4`) exposing CTGAN binning boundaries | 34 | 0.94345 | **+0.00160** |
| **2** | **Frequency Encoding:** Global value prevalence across numeric and categorical features | 47 | 0.94382 | **+0.00037** |
| **3** | **In-Fold Target Encoding:** Multi-smoothing (`auto`, 10, 100) strictly fit inside training folds via `TargetEncoder` | 47 | **0.94550** | **+0.00168** |

---

### 3. Model Architecture & Frontier Ensembling

- **Diverse Model Families:**
  - **Generator-Aware Ridge:** Ridge logistic regression leveraging linear propensity interaction features.
  - **LightGBM Phase 1:** 75-feature multi-seed tree model combining digit ladders and dual target encodings.
  - **CatBoost Digit Ladder:** Depth-5/6 symmetric trees capturing high-cardinality interaction manifolds.
  - **Hist-XGBoost:** Complementary tree builder providing noise-hedged predictions.
- **Blending in Probit / Rank Space:**
  - Converted predictions to normal quantile scores: $z = \Phi^{-1}\left(\frac{\text{rank}(p)}{N + 1}\right)$
  - Applied linear solver optimization on OOF predictions to calculate optimal weights across orthogonal model families.
- **Empirical Boundary Clamping:** Clamped deterministic manifolds (e.g. `Annual_Income_USD >= $170,537` $\implies 1.0$) to guarantee boundary purity.
